# 1. 先不谈硬件：一个神经元到底算什么？

本章只做推理中的一小段计算，不需要先会训练模型。

## 1.1 从四次乘法开始

假设我们有四个输入：

```text
输入x： 1   2   3   4
权重w： 2  -1   3   1
```

每个输入乘以对应权重，然后相加：

```text
1×2   =  2
2×-1  = -2
3×3   =  9
4×1   =  4
        ──
总和  = 13
```

这叫点积。权重只是“这个输入以多大正负程度参与结果”的系数。这里为了教学直接给出数值，不是从训练中得到的模型参数。

软件用一个循环计算：

```c
int32_t sum = 0;
for (unsigned i = 0; i < n; i++)
    sum += (int32_t)x[i] * (int32_t)w[i];
```

逐句看：sum初始化为0；i依次选择每个元素；读取x[i]、w[i]；先扩成有符号32位再相乘；把乘积加入sum。负权重可以减小结果，所以不能随便把所有东西当无符号数。

硬件加速的起点，就是让多个乘法在同一份电路里并行进行，再把乘积相加。

## 1.2 一个神经元再多哪两步？

常见结构是：

```text
输入与权重点积 → 加偏置bias → 激活函数 → 输出
```

偏置是额外加上的数；ReLU是一种简单激活：正数保留，负数变0。

```c
int32_t activated = sum > 0 ? sum : 0;
```

不是所有网络都使用ReLU，本章选择它是因为行为很容易检查。

## 1.3 本章实际C程序中的全连接层

打开[main.c](../main.c)开头：

```c
static const uint8_t inputs[8] = {1,2,3,4,5,6,7,8};
static const int8_t weights[2][8] = {
    { 2,-1,3, 1,-2,1, 0,2},
    {-1, 0,1,-2, 1,1,-1,0}
};
static const int32_t biases[2] = {3,-2};
```

有8个输入、两个输出神经元。每个神经元都接收这8个输入，但使用自己的8个权重，这就是这里“全连接”的含义。

第一个输出：

```text
前4项：2-2+9+4       = 13
后4项：-10+6+0+16    = 12
点积：13+12          = 25
加偏置：25+3         = 28
ReLU：max(0,28)      = 28
```

第二个输出：

```text
前4项：-1+0+3-8      = -6
后4项：5+6-7+0       = 4
点积：-6+4           = -2
加偏置：-2-2         = -4
ReLU：max(0,-4)      = 0
```

所以日志必须出现[28,0]。

```text
同一个inputs[8]
    ├─ 与weights[0][8]点积 ─ +3  ─ ReLU → 28
    └─ 与weights[1][8]点积 ─ -2  ─ ReLU → 0
```

神经元的个数2、输入长度8都只是本章示例，不是CFU硬件固定只支持两个神经元。硬件每条累加命令处理4对元素；更长的点积由软件分批送入。

## 1.4 哪一部分真的被加速？

```text
CPU：读取数组、打包、选择权重、清累加器、循环、加bias、ReLU
CFU：每次四对数相乘，四个乘积相加，再加入累加器
```

本章没有把整个神经网络都搬到硬件，bias和ReLU也没有放进CFU。可以在main.c里直接找到它们仍由C执行。

## 1.5 为什么叫INT8，结果却是32位？

权重用8位有符号整数，范围-128～127；本章输入用8位无符号数，范围0～255。两个小整数相乘后，数值范围已经超过8位；多次相加还要更宽。

一项乘积范围为-32640～32385，16位有符号数可容纳；四项和范围为-130560～129540，至少需要18位有符号表示。核心用32位累加器，为多次命令积累留出空间。

更长点积仍可能溢出32位，硬件会保留低32位。本章最长17元素，正常数值范围远小于32位边界；没有把本次对拍称为所有溢出情况已验证。

本章还没有讲量化比例scale、通用zero_point和输出重定标；因此它是整数神经网络算子基础实验，不冒充完整TFLite量化推理实现。
