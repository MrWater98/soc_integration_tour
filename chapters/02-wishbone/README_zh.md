# 02 — Wishbone 从设备接口合同

## 集成变更

运行 Migen 仿真，由确定性的 Wishbone 主设备访问字节地址 `0x1000`（字地址 `0x400`）上的 32 位寄存器从设备。寄存器初值为 `0x11223344`，写操作支持四个字节通道。

检查器把每个时钟周期记录为 CSV 和 VCD，覆盖读、写、读回、等待 0/2 周期、单字节通道、无 ACK、空闲 ACK、完成后 ACK 保持以及无人响应的地址。

## 运行与验收

```sh
python3 chapters/02-wishbone/verify.py
python3 chapters/02-wishbone/verify.py --case wait2
```

默认运行必须为每种情境打印 PASS；协议断言或超时检查失败时返回非零。输出位于 `results/02/`。

## 接口约束

| 信号 | 方向 | 合同 |
| --- | --- | --- |
| `cyc`、`stb` | 主到从 | 活动请求时同时为高 |
| `adr`、`we`、`sel`、`dat_w` | 主到从 | 等待应答时地址、操作、字节通道和写数据保持稳定 |
| `dat_r`、`ack`、`err` | 从到主 | 读数据、完成或错误应答 |

本测试使用 32 位字寻址总线：字节地址 `0x1000` 对应 `adr=0x400`。ACK 只对活动请求有效，并且只接受一个响应周期。故障注入模式只属于验证模型。
