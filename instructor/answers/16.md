# 16 上板冒烟：参考答案

1. USB 枚举证明电脑能看到 USB 桥，CPU 活动还需要固件标记。
2. SRAM 配置掉电丢失，重上电可能加载原有 Flash 内容。
3. 心跳证明时钟/复位/计数/LED 路径活动；HELLO 还经过 CPU 取指、固件执行、CSR 和 UART。
4. 修改电脑端串口波特率，记录新配置并重新构建。
5. 串口序号由枚举顺序决定，使用检测到的稳定 by-id 路径。
6. 不同。同步器降低跨时钟域采样风险；消抖处理机械触点多次变化。

7. 否，硬 PLL 和电气连接需实测。
8. 否，本版内存图的 main RAM 仍是片内存储器。

综合题：先核对板号、1 号使能和供电；确认连接下载串口接口和数据线；核对真实串口路径、115200/8N1，并捕获后续 ALIVE；重新 SRAM 下载并用复位按钮观察 HELLO。如果仍只有心跳，检查 CPU ROM、复位、UART CSR 与引脚，保存检测、下载和串口日志，不凭 LED 推断 CPU 正常。
